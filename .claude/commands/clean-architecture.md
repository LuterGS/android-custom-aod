# v2 아키텍처 점검

`CLAUDE.md`, `docs/design.md`, `docs/validation.md`를 읽고 현재 코드를 검토한다.

1. domain에 Android 의존성이 없는지 확인한다.
2. 화면·센서·미디어·알림 자원의 등록/해제와 지연 작업 취소를 확인한다.
3. 콘텐츠는 이벤트로 갱신하고 최대 1fps 제한을 통과하는지 확인한다.
4. 가림·전원 키·잠금 해제·접힘/펼침의 경합과 세션 ID 처리를 확인한다.
5. 알림 개인정보 정책과 단위 테스트를 확인한다.
6. 변경 후 빌드·Lint·정책 테스트를 수행하고 실기기 미검증 항목을 명시한다.
