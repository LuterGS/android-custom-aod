SG AOD는 Android 12 이상에서 사용하는 커스텀 Always-On Display 앱입니다. 검정 배경에 시계, 날짜, 배터리, 앱 알림과 음악 상태를 표시합니다.

주요 기능
• 시계·날짜·오전/오후 크기와 전체 배율 조절
• 테마 색상 프리셋 6개와 직접 색상 입력
• 우선 앱 별도 표시와 알림 표시 개수 설정
• 알림 시간의 상대시각·절대시각 선택
• 시스템 자동 밝기 연동 또는 수동 밝기 설정
• 충전 상태와 기기가 제공하는 완충 예상 시간 표시
• 설정을 적용한 AOD 미리보기
• 센서 지원 여부에 따른 가림·뒤집힘 감지, 배터리 부족·발열·취침 시간 등의 자동 암전

개인정보와 권한
인터넷 권한, 광고, 사용 분석 기능이 없습니다. 알림과 음악 정보는 메모리에만 유지하며 저장하거나 전송하지 않습니다. 알림과 음악 표시에는 선택적으로 알림 접근을 허용해야 합니다. 자동 표시에는 다른 앱 위에 표시 권한이 필요합니다. 전화 상태 권한을 허용하면 통화 중 AOD를 종료합니다. 사용자가 켠 기능을 유지하기 위해 포그라운드 서비스를 사용합니다.

사용 방법
기기의 기본 AOD를 끄고 SG AOD를 켠 뒤 화면을 잠그세요. AOD에서 두 번 탭하거나 볼륨 키를 누르면 닫힙니다. 백그라운드 실행 제한과 센서 지원은 기기에 따라 다릅니다.

전력과 화면의 한계
일반 Android Activity를 표시하므로 제조사 시스템 AOD와 같은 소비전력을 보장하지 않습니다. 화면에 1Hz를 요청하지만 OS가 무시할 수 있습니다. 앱 콘텐츠는 최대 초당 한 번 갱신하고, 다른 변경이 없으면 시계를 분 단위로 갱신합니다. 매분 픽셀을 이동해 번인 위험을 줄이지만 완전히 방지할 수는 없습니다. 암전 시에도 패널이 즉시 꺼지는 것은 아닙니다.
